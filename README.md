# 仁和街道法拍房数据档案

`fapai_renhe` 是一个面向杭州市余杭区仁和街道的历史法拍房数据档案项目。它将公开拍卖公告、房源详情及已下载的附件、多媒体素材按“社区 / 小区 / 门牌号”归档，并提供网页端和 uni-app（跨端应用）端的离线查询界面。

> 项目保存的是一次历史数据快照，而非实时交易或法律服务。房源状态、价格、公告与外链可能已经变化；使用前应以原始公告和相关官方渠道为准。

已归档房源可包含结构化基础信息、原始公告与拍卖链接、附件、图片、视频，以及由 MineU 解析出的附件 Markdown。并非每套房源都具备每一种素材或全部字段。

## 已实现能力

- 从人民法院诉讼资产网的检索结果中保存分页公告与详情解析结果。
- 依据关键词白名单与黑名单筛选房产记录，并按社区、小区、门牌号归档详情数据。
- 保存房产基础字段、公告与拍卖链接，以及可取得的附件、图片和视频。
- 将社区清单和每套房源的 `基础信息.json` 聚合为静态 JSON 数据。
- 提供 Vue 3 + Vite + Element Plus 网页端：按社区、小区、地址、房间号筛选并分页浏览房源。
- 提供 uni-app + Vue 3 移动端：搜索、筛选、下拉刷新、列表分页和结构化详情页；支持 H5、微信小程序与支付宝小程序构建命令。
- 提供附件大文件扫描、数据质量统计、离线重解析和 MineU 附件转 Markdown 等维护脚本。

## 快速开始

### 网页端

网页端读取 `web/public/community.json` 和 `web/public/house.json`，不依赖后端服务。

```bash
cd web
npm ci
npm run dev
```

构建静态文件：

```bash
cd web
npm run build
```

### uni-app 端

移动端将 JSON 内联到构建产物中，以避免小程序运行时读取大 JSON 文件的问题。

```bash
cd app
npm ci
npm run dev:h5
```

其他已定义构建目标：

```bash
npm run build:h5
npm run build:mp-weixin
npm run build:mp-alipay
```

微信小程序的实际发布、域名配置和账号资质不在本仓库中管理。

## 数据与目录

```text
仁和街道小区.md                    # 社区与小区清单
result/                              # 公告列表、详情、筛选结果、进度与日志
仁和社区总览/<社区>/<小区>/<门牌号>/ # 每套房源的归档目录
├── 基础信息.json                    # 结构化房源字段
├── 附件/                            # 原始附件与已解析的 Markdown
├── 图片/                            # 房源图片
└── 视频/                            # 房源视频
web/                                 # Vue 3 + Vite + Element Plus 网页端
app/                                 # uni-app + Vue 3 移动端
scripts/                             # 抓取、修复、统计与解析脚本
build_data.py                        # 构建网页端静态 JSON
```

`基础信息.json` 的公共字段包括公告法院、发布日期、房产地址、拍卖轮次、原始公告链接、拍卖链接、评估价、起拍价，以及可从详情中解析到的面积、用途、楼层、建成年份、占有或租赁情况等。字段是否存在取决于原始公告内容。

详细的数据流、更新步骤、维护命令和外部服务要求见 [数据维护说明](docs/数据维护.md)。

## 数据来源与使用边界

- 数据源为公开页面中的历史拍卖信息；数据抓取和使用应遵守来源网站的条款、robots 规则、访问频率要求及适用法律。
- 来源站点可能拒绝自动化请求，页面结构与访问规则也可能变化。仓库中的历史抓取脚本不保证在任意时间、任意网络环境下都能运行。
- 不要通过绕过访问控制、规避反爬机制或提交会话 Cookie、密钥等方式更新数据。需要重新抓取时，应先确认已取得必要授权。
- `MINEU_API_KEY` 只应通过本地环境变量提供，绝不可提交到仓库、日志或文档中。
